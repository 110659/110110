## 管理员端功能（对照需求文档）

对商家：① 入驻审核（资质/营业执照/校园准入承诺书，通过/驳回）② 商家管理（新增/禁用/下架/编辑/营业状态）③ 菜品审核（违规直接下架）④ 费率设置（平台抽成/配送费规则/优惠活动权限）⑤ 订单查看（全部数据 + CSV导出）⑥ 结算管理（每周一结/发起打款/账单/冻结违规商家资金）⑦ 处罚管理（警告/限时停业/清退）⑧ 活动配置（满减/优惠券/限时）
对用户：① 用户账号管理（列表/封禁恶意刷单差评用户/解封）② 用户反馈（查看/分配客服/办结）③ 优惠券管理（发放/收回）④ 用户数据看板（注册量/活跃/下单频次/客单价）⑤ 评价管理（删除恶意违规评价）

## 客服端功能

对商家：① 商家咨询接待 ② 订单异常同步（一键上报）③ 权限/资金/审核问题收集上报 ④ 订单与账单只读查询 ⑤ 商家申诉记录取证上报
对用户：① 咨询接待（查进度/退款/配送）② 售后处理（协助退款，纠纷上报判定）③ 差评沟通（发起和解会话，无删除权）④ 投诉记录提交管理员判定 ⑤ 账号答疑

校园场景：管理员管控进校园商家与配送范围；客服重点处理超时、取餐点冲突、学生投诉。

## 内置实时数据库 + 云端双向同步（v3.2）

种子数据：60商户 / 28订单 / 10用户 / 3入驻申请 / 4待审菜品 / 8结算账单 / 2处罚记录 / 3活动 / 3反馈 / 2上报 / 5会话 / 18评价 / 5售后。

**云端实时互通（Netlify Functions + Blobs，随站点自动部署）**：
- 后台每 3 秒拉取云端库，操作后自动推送；小程序每 5 秒拉取，下单/评价/售后即推。
- 后台 → 小程序：推进订单状态、处理售后、删除评价、禁用/下架商家（前端显示「暂停营业」）、发放优惠券（前端券包自动到账）。
- 小程序 → 后台：新订单实时进入后台「实时订单」、评价进入「评价管理」、售后申请进入「售后处理」、订单状态推进同步。
- 合并规则：按记录 id 联合，按更新时间戳「后写优先」，双端互不覆盖。

## 部署（重要：需包含 functions 目录）

把**整个文件夹**（含 `netlify/functions/`、`node_modules/`、`netlify.toml`、`package.json`）压缩后拖到 https://app.netlify.com/drop ，或在 Netlify 站点 Deploys 手动上传 zip。**切勿只传 index.html**——缺少 netlify/functions 时云端互通退化为本地演示模式（页面功能不受影响）。

部署完成后打开站点 → 系统设置 → 同步状态应显示「云端已连接 · 与小程序实时互通」。

## 与小程序互通

小程序 `utils/cloud.js` 的 `CONF.BASE_URL` 默认已填本站点地址（更换站点时同步修改）。微信开发者工具中勾选「不校验合法域名」即可联调（正式发布需在小程序后台把站点域名加入 request 合法域名）。

## 演示互通的操作建议

1. 小程序下单 → 后台「实时订单」立即出现该订单。
2. 后台订单页点「推进」→ 小程序订单详情状态条实时变化。
3. 小程序申请售后 → 后台「售后处理」出现；后台「同意」→ 小程序进度变「退款成功」。
4. 后台「商家管理」对某店「禁用」→ 小程序该店显示红色「暂停营业」横幅且无法下单，分类列表卡片出现「暂停营业」标签。
5. 后台「活动配置」新增优惠券（填面额）→ 小程序「神券/我的」券包自动到账。
6. 后台「评价管理」删除某条评价 → 小程序评价平台该条立即隐藏。
7. 小程序写评价 → 后台「评价管理」立即出现，可删除回传。
